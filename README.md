
# Housing Price Prediction with Streamlit and Random Forest

This project leverages a Random Forest Regressor to predict housing prices based on features like area, bedrooms, bathrooms, and amenities. It integrates model explainability (via SHAP and feature importance plots) with a real-time Streamlit web app for interactive price predictions.

-----

Description

Predicts house prices using structured features

Offers interpretability via feature importance and SHAP values

Delivers a user-friendly experience through a web dashboard
